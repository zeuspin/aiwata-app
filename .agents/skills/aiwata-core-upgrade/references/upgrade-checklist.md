# 升级核对单

这是执行检查入口，不是永久冻结上游实现。具体模块从当前源码定位；当前规范优先于历史批次。

## 可恢复性与作用域

- 保护两个源码仓库及untracked的宿主/安装器新模块；只打tracked diff会漏功能。快照排除密钥、认证/会话数据、日志、依赖和私有分发资源，恢复验证在临时目录进行。
- 定制库存check发现漂移先解释，不直接write掩盖；迁移验收成功后再更新基线/库存。
- 候选home、PM runtime、desktop userData明确隔离；目录隔离不是OS权限隔离。工具与配置环境变化不得修改原用户共享PM目录。
- 并发前端工作与核心迁移约定写入范围。保留已安装App/用户数据，未获安装授权只验候选与制品，不停真实实例。

## 原生合同

| 检查面 | 行为判据 |
| --- | --- |
| 默认renderer | 核心dev/build选新前端，legacy仅显式入口；候选编译绑定候选SDK，Mock/Sites不依赖核心源码。 |
| 原生client | 握手/请求/事件/历史snapshot匹配目标合同；发送丢响应后按原生幂等身份恢复；超过数次失败仍能重连，不永久缓存reject。 |
| 归属 | 账号/Bot Profile区分；切换/登出/重连取消旧请求，异步结果按原所属处理，不落入当前选中对象。 |
| 消息能力 | 普通/Bot/托管群分别测：流式、审批/拒绝、排队、stop/retry、历史工具卡、冷重开与后台任务；群成员工具范围保持原生策略。 |
| 模型/凭据 | 空档案默认路由在CLI和网关都生效，显式模型/URL不污染，凭据仍后端managed scope；不恢复已去掉的Nous guest等产品入口。 |
| 原生工具 | 当前会话owned webview、目录选择、PTY、DevTools开关事件、标注截图/加入精确接收方草稿；不以浏览器自动化替代专用Computer Use验收。 |
| 分发 | 原宿主+新静态renderer入校验归档，不依赖前端checkout；正式App、独立安装器、验属原子发布/中断恢复、完整修复缓存与CLI启动入口保持一致。 |
| 窗口 | 系统安全区/全屏状态/overlay来自宿主，加载/失败/登录页也可操作窗口；Mac结果不代表Windows/Linux。 |

配置入口移动要沿实际生产调用链检查：CLI配置通过不代表gateway policy构建/恢复成功。上游已实现等价行为时可以退休补丁，但须有行为证据；不盲目保留旧文件，也不因同名函数删除定制。

## 完成标准

先跑与迁移有关的核心测试、Electron类型/构建、新前端测试/native构建及Mock/Sites检查，再以原生宿主和新后端隔离验收；需要真实模型时最小调用、不输出凭据。打包/覆盖单列。测试数量、模型和平台均记录当轮事实。

每个回归分清旧基线失败、目标上游失败、新适配回归；有失败列名称、证据与影响，不能静默豁免。未支持/未验证功能继续标明，不隐藏主导航入口或伪装成功。

切换串行；schema变更要保护一致性数据与格式兼容，回退不能让旧代码强改新数据。完成后追加核心定制记录、更新state和库存；未通过则保留原已验证基线。不要为了“完成流程”提交、推送或覆盖用户安装。
