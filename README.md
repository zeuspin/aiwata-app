# AIWATA App 前端

AIWATA 工作台的独立前端工程，从高仿真原型继续开发。目前默认使用本地 Mock。选择「林晓」体验完整工作区，选择「乔安」体验另一套数据和零积分状态。两套数据分别保存在此原型的浏览器存储中。

使用 Node.js 24 开发：

```sh
npm ci
npm run dev
```

提交前验证：

```sh
npm test
npm run build
npm run test:sites
```

开发预览地址为 `http://127.0.0.1:4178/`。原型使用合成数据。录音使用浏览器麦克风，转写、Agent、网页操作、后台任务和积分扣除在本地演示。参见 [AIWATA 接入参考](docs/aiwata-integration.md)。

## 操作路径

- 在项目中创建或切换会话，打开右上工具区，分别拖动项目栏与工具栏的边界。
- 从分栏进入工具完整视图，再恢复分栏。观察宽度、标签和草稿。
- 打开多个工具标签。将指针停在标签上查看缩略图，标签溢出时在标签栏上滚动。
- 打开左下积分余额或账号菜单。用乔安尝试发送托管消息，再切换本地模型发送。
- 在会话底部选择「演示场景」，发送后体验流式回复、审批、追问、子 Agent 和浏览器联动。会话运行期间可以排队发送。
- 从左侧管理项目目录、Bot 和群聊、任务、连接器、技能与记忆。在账号菜单模拟断网或退出。
- 在右侧体验文件预览、浏览器批注、模拟终端和 Git，或按供应商能力体验媒体工具。
