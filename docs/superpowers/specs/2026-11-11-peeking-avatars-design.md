# 探头头像部件系统

用户已确认最新单人样稿与十张系列样稿，并要求结构化拆分、可随机生成，发型和头饰是主要视觉特征。本实现延续已经批准的完整面部、左侧倾斜探头、少量肩颈、豆形眼睛和双色头发。

## Approaches

采用项目已有的 SVG 部件组合方式，新增独立 peeking 系列。PNG 整图预设不支持独立改色与换部件；在线图片生成无法保证部件边界和动画一致，均不用于运行时生成。

## 结构与约束

- 背景 → 后发与头饰后带 → 肩颈 → 耳朵与脸 → 前发 → 头饰 → 腮红与眼睛 → 眼镜与耳饰。后发不能覆盖肩颈。
- 36 种独立命名的发型，通过前发、后发、轮廓与高光组成；32 种头饰（另有无头饰），包括东方巾冠、簪钗、丝带及现代帽饰。
- 独立保存发型、头饰、发色、头饰色、肤色、脸型、眼镜、耳饰、衣服色、背景色。参数均校验并提供默认值。
- 发型声明支持的佩戴方式，头饰声明挂载位置。随机和手动选择都遵守适配约束；换发型时只清除不兼容头饰，并明确提示。
- 每批十个候选，点击才应用。可以锁定任意部件；锁定发型/头饰后只在兼容集合内随机。随机配色优先保持头发与背景的对比；两个颜色同时锁定时尊重用户选择。
- 同一 Bot 可保留几何、原人物、探头、上传图片四套选择。探头参数随外观保存与恢复，上传图片不丢失。
- 新系列复用眼睛动效与 reduced-motion，不引入嘴部吹泡泡等遮脸动效。
- 纯前端生成，不调用图片生成服务。实时保存沿用现有 profiles.configure 的 aiwata-app 外观元数据；不扩展 Hermes 接口，不在验收时写真实 Profile。
- 不创建分支、不提交或推送，不创建 Docker 容器。保留当前工作区原有更改。

## 交付与验证

在现有头像编辑器展示实时预览、候选和按类别浏览的部件缩略图。测试参数校验、兼容规则、锁定随机、批次差异、配色对比、账号隔离与重载。运行完整测试、构建与 Sites 兼容检查，并打开本机 mock 预览核对样稿构图。
