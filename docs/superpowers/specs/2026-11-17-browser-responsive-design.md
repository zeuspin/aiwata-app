# 浏览器响应式预览

用户提供截图并要求常见手机型号与手动输入，明确选择“只调整预览宽高”。方案：复用现有原生webview，通过CSS真实布局宽高触发网页响应式断点；外层独立显示缩放。无需Electron设备模拟、移动UA、触控或DPR变更。

浏览器工具栏增加设备尺寸按钮，展开与截图类似的尺寸条：设备预设、自定义宽×高、横竖屏交换、适应窗口及50/75/100/125/150/200%缩放。预设取Chrome DevTools官方EmulatedDevices的CSS逻辑尺寸，覆盖iPhone16/16Plus/16Pro/16ProMax、Pixel7、GalaxyA55/S20Ultra等常见宽度。不声称复现设备浏览器或物理屏幕。

默认关闭，既有页面铺满。开关、尺寸、预设及缩放保存在每个浏览器实例自己的browser.viewport，使用原api.updateBrowser和所属账号存储；导航保留，同聊天其他浏览器独立。手动宽高200–3840整数，Enter/失焦提交，错误不破坏上次有效尺寸；自定义后标明“自定义”。

Webview保持同一DOM实例，不因开关/型号/宽高变化重载；stage居中并可滚动，适应窗口只缩小到可见范围，不改网页ZoomFactor。标注和原生输入仍用网页坐标；宿主批注卡按展示偏移/比例定位。控制台及批注控制条保持正常界面大小。关闭预览模式恢复流式铺满。原生权限、所属、URL策略及标注草稿不扩大。

验证：真实React交互、尺寸校验/布局数学、独立浏览器持久化，完整前端测试和原生构建。原生Electron打开本机合成网页，检查innerWidth/innerHeight、CSS断点、点击/输入/滚动、同一webContentsId、标注/截图及关闭恢复；两种面板宽度下截屏。无模型测试、无Docker/安装/分支/推送。
