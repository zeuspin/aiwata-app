# AIWATA 工作台原型

录屏取证报告的空会话、分栏和完整视图是界面参照。原型独立于 AIWATA 仓库，运行在 127.0.0.1:4178，使用各账号的合成数据。React 负责界面，Vite 提供本地预览，Node 测试覆盖状态约束。

1. 为 `src/workspace.mjs` 先编写状态测试。验证相邻区域拖动、缩窄与恢复、账号草稿隔离、离线锁定、退出后禁止后台触发、托管扣费去重与余额不足。
2. 实现布局计算与 Mock 工作区服务。工作区记录按账号存储，工具标签和草稿归会话，拖动尺寸归工作区，视图切换独立于会话数据。
3. 在 `src/App.jsx`、`src/workbench.jsx` 和 `src/surfaces.jsx` 组装登录、图标导航、上下文列表、会话、输入区、标签和工具面板。以中性色、细分隔、系统字体、44 px 顶栏、50 px 图标栏和约 200 ms 的侧栏过渡对齐录屏。窄窗口行为是原型设定。
4. 跑状态测试和构建。浏览器验证项目会话到工具完整视图的路径，比较参考帧，检查工作区数据与源仓库边界。
