# Bot 和群聊对齐计划

**目标**：在现有工作台内完成 Bot 身份与群聊协作流程，并按已核对的 AIWATA 网关边界设计。

**结构**：沿用会话输入、消息和本地队列；群聊另有成员、讨论和动作状态。Bot 配置按 Profile 管理。保持纯本地演示。

- [x] 测试定向提及、引用跨队列保持、讨论上限与继续；实现群聊参数、成员事件和对应动作。
- [x] 在会话顶部展示群成员和状态，在消息区提供引用、继续、重试和按成员审批；群设置展示固定成员。
- [x] 补 Bot 私聊身份、Profile 创建和复制、模型与能力设置，以及跳转 Profile 关联模块的入口。
- [x] 对齐定时任务投递目标，更新集成文档；运行现有检查并在本地预览核对交互。

关注引用草稿在发送失败时保留、继续不重发消息、审批只影响对应尝试、换页和退出时不串会话。正式接入以网关能力探测为准。
