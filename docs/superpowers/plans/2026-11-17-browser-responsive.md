# 浏览器响应式预览实施

1. browser-viewport.mjs：受限设置、设备数据、适应缩放和坐标换算；行为测试覆盖无效输入、旋转、自定义和每实例持久化，先红后绿。
2. browser-viewport.jsx/.css：尺寸条和真实尺寸/展示缩放容器；不重载子webview；沿用现有图标/颜色/字号与窄工具面板换行。
3. live-browser.jsx接入持久化设置、工具栏开关、Page内部常驻容器及宿主标注卡坐标转换；UI生命周期与StrictMode/卸载边界验证。
4. 完整前端测试、原生构建与原生合成网页验收，必要时修正坐标；记录实际已验范围和已知限制，保持源码窗口可供用户测试。
