# 探头头像部件与扩展

视觉基准是用户确认的完整面部单人图及十张系列样稿：头部顺时针倾斜，从左侧探入，双颊和下巴保留完整，左下露少量肩颈。运行时以可分别改色的 SVG 路径组合；发丝细节经过矢量化简化，生成不依赖远程模型。

## 参数

| 字段 | 含义 | 首版数量 |
| --- | --- | --- |
| `hair` | 发型：前发、后发、轮廓与高光的组合 | 36 |
| `headwear` | 巾冠、簪钗、丝带、发带、发夹、现代帽饰 | 32，另有无头饰 |
| `hairColor` | 独立的头发底色与高光 | 16 |
| `headwearColor` | 头饰底色与高光 | 12 |
| `skin` | 肤色、阴影与腮红 | 10 |
| `face` | 脸型 | 4 |
| `eyewear` | 眼镜；与耳饰独立 | 5，另有无眼镜 |
| `earrings` | 耳饰；与头饰独立 | 6，另有无耳饰 |
| `clothing` | 肩部衣服与领口配色 | 10 |
| `background` | 纯色背景 | 12 |

眼睛固定为可独立动画的黑色豆形，不随机添加鼻子、嘴或眉毛。

```json
{
  "mode": "peeking",
  "peekingDesign": {
    "hair": "loopBun",
    "headwear": "jadePin",
    "hairColor": "teal",
    "headwearColor": "celadon",
    "skin": "wheat",
    "face": "oval",
    "eyewear": "none",
    "earrings": "jade",
    "clothing": "jade",
    "background": "peach"
  }
}
```

## 文件职责

- `src/bot-peeking.mjs`：部件 ID、分类、配色、预设、适配、参数校验和随机逻辑。保存的是 ID，颜色与几何分离。
- `src/bot-peeking-art.mjs`：脸部、前发、后发与头饰的 SVG 路径。每个部件分别包含 `base`、`highlight`，头饰可增加 `trim` 与 `rear`。
- `src/bot-peeking.jsx`：按图层顺序合成，负责脸部、眼睛、眼镜、耳饰与头饰挂载。
- `src/bot-peeking-picker.jsx`：预设、十个随机候选、分组部件缩略图、锁定和独立配色。
- `src/bot-appearance.mjs`：接入既有外观读取与保存。切换系列保留探头参数、原人物参数和上传图片。

## 图层与坐标

统一使用 100×100 的头部坐标，再缩放到 BotFace 的 64×64 viewBox。圆角裁切只裁外围头发与衣服，不裁脸。

绘制顺序：背景 → 后发 → 头饰后带 → 肩部 → 颈部 → 耳朵 → 脸与侧影 → 前发 → 头饰 → 腮红 → 眼睛 → 眼镜 → 耳饰。

后发必须在颈部后面，避免把后发绘成下巴周围的一圈色块。帽体使用头部原点；簪钗和丝带使用发型的 `anchor: [x, y, rotation?]`；发夹使用侧鬓位置。较低的发髻需调整挂载角度，避免簪杆跨过眼睛。

## 发型与头饰适配

发型用 `slots` 声明可佩戴部件：

| slot | 用途 | 规则 |
| --- | --- | --- |
| `cap` | 纶巾、方巾、帽子 | 适配较低的短发、披发、编发；避开高髻、马尾和圆蓬卷发 |
| `pin` | 发簪、步摇、束发小冠 | 盘发、束发，通过发髻挂载点定位 |
| `tie` | 丝带、发绳 | 盘发、束发，通过束发点定位 |
| `band` | 发带、抹额 | 所有发型 |
| `clip` | 一字、星星、月牙、叶片发夹 | 所有发型 |

手动换发型时，清除不适配的新旧头饰并提示；已锁定头饰时，不允许切换为不兼容的发型。无效保存值退回默认，避免损坏的部件 ID 造成无法打开编辑器。

## 随机与锁定

`randomPeekingBatch({ design, locked, count = 10, rng = Math.random })` 输出完整、可保存的参数对象。

- 未锁定发型时，一批优先给出不同的发型；锁定头饰时只在其兼容发型内选择。
- 发色与背景自动筛选，头发底色和高光对背景的对比均至少 3:1。两个颜色都被锁定时保留用户选择。
- 未锁定头饰颜色时，同样筛选对背景的对比。
- 参数整体去重，并有有限的尝试次数。所有字段锁定时只显示一个结果，不无限重试。
- 生成候选不更改当前头像；点击才应用。手动调整部件、改变锁定条件后，旧候选立即失效，避免覆盖新的锁定值。
- 锁定条件仅用于本次编辑；头像参数随 Bot 保存。

## 扩充方式

1. 在 art 文件添加新前发、后发或头饰路径，用相同头部坐标与双色图层。
2. 在目录文件注册稳定 ID、中文名称和分类。新发型声明前后发、佩戴 slot 与 anchor；新头饰声明 slot。
3. 用现有发色、肤色与背景检查小尺寸效果。避免通过复制同一轮廓仅改颜色来充数。
4. 验证高髻、低髻、长发、短发与眼镜组合，确保两眼和完整下巴仍然可见。现有渲染测试遍历所有发型和所有头饰。

东方巾冠与簪钗是角色化图形，并非历史服饰考据复原。
